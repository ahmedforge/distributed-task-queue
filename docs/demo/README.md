The demo used three initial successful jobs, one deliberately corrupt PDF, a real 30-page browser upload, and a later batch of eight 12-page PDFs. A screenshot of the queue history can show an active-job spike after the jobs have completed; panel counts reflect the captured moment. Grafana's demo job totals are separate from the 40-job recorded benchmark.
